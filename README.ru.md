# HayRus

Android-приложение для голосового перевода между русским и армянским языками. Разговорник для живого общения "лицом к лицу": один человек говорит по-русски, другой — по-армянски, перевод показывается и озвучивается сразу после того, как говорящий отпускает кнопку записи.

Работает по принципу push-to-talk (зажал — сказал — отпустил).

## Возможности

- Распознавание речи на русском и армянском
- Перевод текста между языками (голосом или вручную введённым текстом)
- Озвучка перевода нейронным голосом, с возможностью повтора на обычной или медленной скорости
- Режим "лицом к лицу": два независимых чата на экране (верхний можно развернуть на 180° для собеседника напротив), каждый со своей кнопкой записи.

## Стек технологий

- **Kotlin** + **Jetpack Compose** — UI и логика
- **Azure AI Speech SDK** — распознавание речи, перевод и синтез речи (Speech-to-Text, Speech Translation, Text-to-Speech)
- **Azure Translator Text API** — перевод вручную введённого текста
- **Kotlin coroutines** — асинхронные вызовы к Azure без блокировки интерфейса

## Требования

- Android 12 (API 31) и выше
- Ресурсы в Azure (портал Microsoft Azure): **Speech** и **Translator** — бесплатного тарифа F0 достаточно для разработки

## Настройка проекта

1. Создать ресурс **Speech** в [Azure Portal](https://portal.azure.com) (издатель — Microsoft).
2. Создать ресурс **Translator** там же (тип — Global).
3. В разделе **Keys and Endpoint** каждого из созданных ресурсов скопировать ключи и регион.
4. В корне проекта в файле `local.properties` добавить:

   ```properties
   AZURE_SPEECH_KEY=ваш_ключ_speech
   AZURE_SPEECH_REGION=ваш_регион
   AZURE_TRANSLATOR_KEY=ваш_ключ_translator
   ```

5. Синхронизировать и собрать проект (**Build → Rebuild Project**) — значения подтянутся в `BuildConfig`.
