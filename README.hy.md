# HayRus

Android հավելված՝ ռուսերեն և հայերեն լեզուների միջև ձայնային թարգմանության համար։ Զրույցի օգնական՝ իրական շփման համար «դեմ առ դեմ» ձևաչափով․ մեկ մարդ խոսում է ռուսերեն, մյուսը՝ հայերեն, իսկ թարգմանությունը ցուցադրվում և հնչեցվում է անմիջապես այն բանից հետո, երբ խոսողը բաց է թողնում ձայնագրման կոճակը։

Աշխատում է push-to-talk սկզբունքով (սեղմած պահել — խոսել — բաց թողնել)։

## Հնարավորություններ

* Ռուսերեն և հայերեն խոսքի ճանաչում
* Տեքստի թարգմանություն լեզուների միջև՝ ձայնի կամ ձեռքով մուտքագրված տեքստի միջոցով
* Թարգմանության հնչեցում նեյրոնային ձայնով՝ սովորական կամ դանդաղ արագությամբ կրկնելու հնարավորությամբ
* «Դեմ առ դեմ» ռեժիմ․ էկրանին ցուցադրվում են երկու անկախ զրույցներ (վերևի հատվածը կարելի է 180°-ով շրջել՝ դիմացի զրուցակցի համար), և յուրաքանչյուրն ունի իր ձայնագրման կոճակը։

## Տեխնոլոգիաների ստեկ

* **Kotlin** + **Jetpack Compose** — UI և ծրագրի տրամաբանություն
* **Azure AI Speech SDK** — խոսքի ճանաչում, թարգմանություն և խոսքի սինթեզ (Speech-to-Text, Speech Translation, Text-to-Speech)
* **Azure Translator Text API** — ձեռքով մուտքագրված տեքստի թարգմանություն
* **Kotlin coroutines** — Azure-ի հետ ասինխրոն հարցումների կատարում՝ առանց ինտերֆեյսի արգելափակման

## Պահանջներ

* Android 12 (API 31) և ավելի բարձր
* Azure-ի ռեսուրսներ (Microsoft Azure պորտալ)՝ **Speech** և **Translator**։ Մշակման համար անվճար F0 պլանը բավարար է։

## Նախագծի կարգավորում

1. [Azure Portal](https://portal.azure.com)-ում ստեղծել **Speech** ռեսուրս (հրատարակիչ՝ Microsoft)։

2. Նույն տեղում ստեղծել **Translator** ռեսուրս (տեսակը՝ Global)։

3. Ստեղծված ռեսուրսներից յուրաքանչյուրի **Keys and Endpoint** բաժնում պատճենել բանալիները և տարածաշրջանը։

4. Նախագծի արմատային պանակում `local.properties` ֆայլում ավելացնել՝

   ```properties
   AZURE_SPEECH_KEY=ձեր_speech_բանալին
   AZURE_SPEECH_REGION=ձեր_տարածաշրջանը
   AZURE_TRANSLATOR_KEY=ձեր_translator_բանալին
   ```

5. Սինխրոնացնել և հավաքել նախագիծը (**Build → Rebuild Project**) — արժեքները կփոխանցվեն `BuildConfig`։
